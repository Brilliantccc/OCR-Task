# 项目3：文档版面分析系统

## 项目概述

| 项目 | 内容 |
|------|------|
| **目标** | 实现文档版面元素检测和分类 |
| **技能点** | LayoutLM、多模态融合 |
| **数据集** | PubLayNet、DocLayNet |
| **下载链接** | PubLayNet: https://github.com/ibm-aur-nlp/PubLayNet ；DocLayNet: https://huggingface.co/datasets/ds4sd/DocLayNet |
| **评估指标** | mAP > 0.90 |

## 技术栈

- **模型架构**: LayoutLM / LayoutLMv3 / DiT
- **检测框架**: Mask R-CNN / DETR
- **多模态融合**: 视觉 + 文本 + 位置信息

## 评估指标

| 指标 | 说明 | 目标值 |
|------|------|--------|
| mAP | 平均精度均值 (IoU=0.5) | > 0.90 |
| mAP@0.75 | IoU=0.75时的mAP | - |
| 每类AP | 各类别单独的AP | - |

## 数据集信息

### PubLayNet
- **来源**: IBM Research Australia
- **规模**: 364,000+ 文档图像
- **类别**: Text, Title, List, Table, Figure
- **格式**: COCO格式
- **下载**: https://github.com/ibm-aur-nlp/PubLayNet

### DocLayNet
- **来源**: IBM Research
- **规模**: 80,863页文档
- **类别**: 11个版面元素类别
- **格式**: COCO格式
- **下载**: https://huggingface.co/datasets/ds4sd/DocLayNet

## 参考资源

- LayoutLM: https://huggingface.co/microsoft/layoutlmv3-base
- 论文: "DocLayNet: A Large Human-Annotated Dataset for Document-Layout Analysis"
