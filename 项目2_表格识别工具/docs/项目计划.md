# 项目2：表格识别工具

## 项目概述

| 项目 | 内容 |
|------|------|
| **目标** | 实现表格检测和结构识别 |
| **技能点** | 目标检测、图神经网络 |
| **数据集** | PubTables-1M |
| **下载链接** | https://huggingface.co/datasets/bsmock/pubtables-1m 或 https://github.com/microsoft/table-transformer |
| **评估指标** | mAP > 0.85 |

## 技术栈

- **表格检测**: 目标检测模型 (YOLO/DETR)
- **结构识别**: 图神经网络 / Table Transformer
- **输出格式**: HTML / Markdown / JSON

## 评估指标

| 指标 | 说明 | 目标值 |
|------|------|--------|
| mAP | 平均精度均值 (IoU=0.5) | > 0.85 |
| Precision | 精确率 | - |
| Recall | 召回率 | - |
| F1-Score | F1分数 | - |

## 数据集信息

- **名称**: PubTables-1M
- **来源**: Microsoft Research
- **规模**: 约100万个表格
- **下载方式**:
  - HuggingFace: `from datasets import load_dataset; dataset = load_dataset("bsmock/pubtables-1m")`
  - GitHub: https://github.com/microsoft/table-transformer
