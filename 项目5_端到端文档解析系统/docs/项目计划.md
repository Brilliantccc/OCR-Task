# 项目5：端到端文档解析系统

## 项目概述

| 项目 | 内容 |
|------|------|
| **目标** | 实现完整的文档解析pipeline |
| **技能点** | VLM、多任务学习、系统设计 |
| **数据集** | 自建数据集 |
| **下载链接** | 无（需自行构建） |
| **评估指标** | 文本识别准确率 > 98%、表格识别准确率 > 95%、公式识别准确率 > 90%、版面分析mAP > 0.92 |

## 技术栈

- **核心模型**: VLM (Qwen-VL / InternVL / PaddleOCR-VL)
- **多任务学习**: 文本识别 + 表格识别 + 公式识别 + 版面分析
- **系统架构**: 模块化Pipeline / 端到端VLM

## 评估指标

| 任务 | 指标 | 目标值 |
|------|------|--------|
| 文本识别 | 准确率 | > 98% |
| 表格识别 | 准确率 | > 95% |
| 公式识别 | 准确率 | > 90% |
| 版面分析 | mAP | > 0.92 |

## 数据集构建

由于是自建数据集，建议：

1. **复用公开数据集**:
   - 文本: ICDAR2019
   - 表格: PubTables-1M
   - 公式: CROHME / HME100K
   - 版面: PubLayNet / DocLayNet

2. **自行标注**:
   - 收集真实文档样本
   - 使用标注工具 (LabelImg / CVAT)
   - 统一标注格式 (COCO)
