# 项目4：公式识别系统

## 项目概述

| 项目 | 内容 |
|------|------|
| **目标** | 实现手写/印刷公式识别 |
| **技能点** | Encoder-Decoder、Attention |
| **数据集** | CROHME、HME100K |
| **下载链接** | CROHME: http://crohme.liris.cnrs.fr/ ；HME100K: GitHub搜索"HME100K"（北京大学高良才团队发布） |
| **评估指标** | BLEU > 0.85 |

## 技术栈

- **模型架构**: Encoder-Decoder + Attention
- **备选方案**: Pix2Tex / LaTeX-OCR / UniMERNet
- **输出格式**: LaTeX

## 评估指标

| 指标 | 说明 | 目标值 |
|------|------|--------|
| BLEU | 机器翻译评估指标 | > 0.85 |
| 编辑距离 | 预测与真实LaTeX的差异 | - |
| 表达式准确率 | 完全正确的公式比例 | - |

## 数据集信息

### CROHME
- **全称**: Competition on Recognition of Online Handwritten Mathematical Expressions
- **类型**: 手写数学公式
- **格式**: INKML
- **下载**: http://crohme.liris.cnrs.fr/

### HME100K
- **全称**: Handwritten Mathematical Expression 100K
- **来源**: 北京大学高良才团队
- **规模**: 约100,000个手写数学公式图像
- **下载**: GitHub搜索"HME100K"获取
